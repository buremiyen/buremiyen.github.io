# buremiyen.github.io

Tamamen statik, ücretsiz kişisel link sayfası.

## Yayınlama
1. GitHub'da public bir repository oluştur: `buremiyen.github.io`
2. Bu klasördeki `index.html` ve `style.css` dosyalarını repository köküne yükle.
3. Repository > Settings > Pages bölümünde Source olarak `Deploy from a branch` seç.
4. Branch: `main`, folder: `/ (root)` seç ve kaydet.
5. Site adresi: https://buremiyen.github.io

## Yeni link ekleme
`index.html` içindeki bir `link-card` bloğunu kopyala, URL ve metinleri değiştir.

## Maliyet
Bu sürüm veritabanı, API, ücretli font, ücretli hosting veya özel domain gerektirmez.
